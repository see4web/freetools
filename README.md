FreeTools

A collection of useful online tools built with PHP for image and PDF processing.

Features
Image Compressor
Image Cropper
Image Resizer
Image to PDF Converter
PDF Compressor
Tech Stack
PHP
JavaScript
HTML/CSS
Project Structure
freetools/
├── page-image-compressor.php
├── page-image-cropper.php
├── page-image-resizer.php
├── page-image-to-pdf.php
├── page-pdf-compressor.php
└── README.md
Installation

Clone the repository:

git clone https://github.com/see4web/freetools.git

Move into the project directory:

cd freetools

Run on local server:

php -S localhost:8000

Open in browser:

http://localhost:8000
